# 0.3.0 紧凑蓝色界面

保留 Tauri 2 / Rust、直接 Keeper API、注册表及代理方案，不增加远程服务。

## 布局

以用户草图为准，舍弃圆球、外环、侧边胶囊和英文装饰标语。常驻组件为 200 × 58 DIP 圆角矩形，原生窗口为 216 × 74 DIP（含 8 DIP 阴影边距）。左侧健康状态点，中间总量 / Token，右侧两行输入与输出。总量 24px、增量 15px 加粗；标签 12px。数值左对齐，紧邻标签。刷新间隔只放提示和详情。

详情窗口为 640 × 640 DIP，宽度比旧版增加 88 DIP，高度减少 72 DIP。四项主指标同排，统一 26px / 700，不再按数字长度单独缩小字号。标签及表格主体 13px，行式数值 14px。减少外边距、卡片内距与圆角；账户页把当前配额移到累计指标之后，账户基础信息放下方。

表格根据字段类型排版：数字、百分比与时间禁止任意换行；名称过长显示省略号，悬停查看全文。额度历史的开始 / 重置时间是有意分为两行。宽请求表在自身容器中横向滚动，不挤压全窗。静态文字禁止选中，输入框等可编辑内容保持正常选择。

## 颜色与字体

浅色背景白 / 浅蓝灰，正文深蓝黑，辅助文字深灰蓝，主色蓝；深色参考用户提供的 Xbox Game Bar 截图的布局与样式原则：石墨灰实底、清晰边框、统一对齐和间距、高对比文字与图标，再用浅蓝强调选中状态；不照搬工具栏结构。健康绿、波动黄、错误红只表达状态。取消透明淡字与悬浮组件位移缩放动画，避免发虚。

悬浮块默认 HarmonyOS Sans SC，缺失时按微软雅黑等系统字体回退，支持用户自定义字体。详情数字使用随包 Manrope。彩色 Keeper 图标保持用户原 SVG，不改变形状和配色。

## 实时显示规则

采样计算保持原样。新增的前端展示状态仅用于悬浮块：输入和输出同时为零时，暂留最近一组非零采样结果，累加有效采样间隔；累计达到 16 秒后一起归零。任一路非零就立即显示本次完整一组值，重新开始零用量计时。以采样时间去重，避免同一采样的事件与调用返回值重复计时。

建立基线、计数重置、断线或重新配置时清空展示历史。详情页不应用暂留，始终呈现真实采样值。保留期间悬停提示会说明暂留状态。

## 原生交互

保持悬停约 180ms 展开、离开约 320ms 收起；穿越区域与边距按 DPI 缩放，原生详情尺寸受当前显示器工作区约束。详情不抢焦点，原生多屏、窗口跨越等仍需 Windows EXE 验收。

预览为示例数据。Chromium 中的 100% / 125% / 150% / 200% 渲染检查不能替代 Windows WebView2、多屏与系统字体的实际验收。
