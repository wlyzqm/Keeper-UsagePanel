# 0.2.0 设计与技术替换

从 WPF 原生控件界面迁移为 Tauri 2 / Rust / 内置 HTML、CSS 和 JavaScript。没有保留 .NET sidecar，没有增加服务器。

## 参考图片的具体取舍

逐张查看了用户提供的[悬浮球设计文章](https://www.woshipm.com/pd/2440034.html)正文示例：

- 360 加速球：圆球主数值 + 辅助胶囊。用于今日总量和两路增量，不照搬其旧式发光效果。
- Soul 播放器：紧凑与展开状态的视觉一致性。圆角、材质和颜色在两窗中保持一致。
- 微信与知乎：移动 / 停靠、收起入口、状态颜色提示。默认不半隐藏，以免遮掉常看数字。
- iOS / MIUI / 钉钉：多操作展开示例，统计工具不需要扇形菜单。
- 美团营销图、强提醒气泡不适合长期桌面监控；不加入吸睛抖动和循环动画。
- 图片中粗白圈、灰色遮罩等多为文章标注，不当作产品 UI 模仿。

## 本版

常驻组件 200 × 84 DIP 左右：今日总量在 84 DIP 圆形区，增量放侧边胶囊。环色只表示健康类别，不伪装进度。详情以数值、表格和可展开错误事件组成，未加入图表。

默认浅色，深色可选。悬浮球默认 HarmonyOS Sans SC，按系统安装情况回退；可自定义。用户提供的彩色 Keeper SVG 同时用于界面与原生图标，不重画形状和配色。

悬停延迟约 180ms，离开延迟约 320ms，球和详情之间有连接区域。详情不抢焦点，点击后才操作控件。Windows 原生交互仍需实机验收。

[Tauri 官方文档](https://v2.tauri.app/zh-cn/)与[Windows 打包说明](https://v2.tauri.app/distribute/windows-installer/)作为实现依据。浏览器截图只证明前端渲染，不证明 Windows 系统行为。
